# LLojenda — Loja virtual completa

Projeto estático em HTML/CSS/JavaScript puro, baseado no layout original enviado.

## Como executar
Abra `index.html` em um navegador. Para desenvolvimento local, também é possível usar qualquer servidor estático (por exemplo, Live Server).

## Funcionalidades
- Home com banners, benefícios e vitrines.
- Catálogo com 28 produtos e ordenação.
- Categorias: Combos, Promoções, Do Dia, Marketplace, Oficiais, BRs e Internacionais.
- Busca de produtos.
- Página de produto com quantidade, favoritos e adição ao carrinho.
- Carrinho com alteração de quantidade, remoção, frete e cupom `LL10`.
- Checkout com dados de entrega e pagamento.
- Login, cadastro, conta do cliente e pedidos.
- Favoritos.
- Páginas institucionais, atendimento, trocas, privacidade e termos.
- Área de venda para lojistas.
- Estado persistido com `localStorage`, sem backend.

## Observação
As imagens de produtos são carregadas de URLs públicas do Unsplash. Para uma publicação real, substitua por imagens próprias/CDN e conecte login, estoque, pagamentos e pedidos a uma API/backend.
